# 📝 LEE SNS 서비스 (SNS Service)
 
NestJS 기반 SNS 서비스 입니다.
 
<br>
 
## 🛠 기술 스택 (Tech Stack)
 
### Backend (leesns-backend)
 
&emsp;**Framework**: NestJS
 
&emsp;**Language**: TypeScript
 
&emsp;**Database & ORM**: PostgreSQL, Prisma
 
&emsp;**Security & Auth**: JWT (@nestjs/jwt), bcrypt, Custom Guards/Pipes
 
<br>
 
### Frontend (leesns-web)
 
&emsp;**Framework**: Next.js
 
&emsp;**Language**: TypeScript
 
&emsp;**Styling**: Tailwind CSS
 
&emsp;**State Management**: Zustand
 
&emsp;**Version Control**: Git
